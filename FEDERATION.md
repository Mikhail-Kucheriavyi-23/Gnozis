# Gnozis Federated Memory Network

Gnozis can connect independent Memory Sources without turning them into one centralized database.

## Model

```text
Memory Source A ─┐
Memory Source B ─┼→ Registry → Graph → Verification → Kernel boundary
Memory Source C ─┘
```

Each source keeps its own governance, revisions, provenance and licensing.

The federated graph primarily stores references and relationships. It does not need to copy every source into Gnozis.

## Cross-domain knowledge

Mathematics can relate to Physics, Physics to Engineering, Engineering to a project result, and the result can contribute back to an appropriate Memory Source.

Every cross-source relationship should retain provenance and revision context.

## Important boundary

Being visible in the federated graph does not make a record trusted. Kernel consumption still follows the Memory Protocol.

This allows the ecosystem to grow from a small set of repositories to many independent research and knowledge communities without creating a single central truth database.
