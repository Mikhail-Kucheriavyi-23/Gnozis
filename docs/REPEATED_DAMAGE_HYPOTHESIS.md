# Repeated damage: structural-memory hypothesis

The next Gnozis research test asks whether experience can persist as a change in `R` without a separate memory store.

Protocol:

1. Start with Ψ=(X,R).
2. Remove the same relation.
3. Run only local endogenous dynamics.
4. Retain the resulting relation structure.
5. Apply the same damage again.
6. Compare the second response with the first.

A difference is only interesting if it is caused by the changed structure itself. The experiment must not provide a repair oracle, external selector, reward model, or hidden history variable.

Interpretation:

- Same response: no evidence of structural memory.
- Different response caused by `R` change: evidence for structural memory/adaptation.
- New viable relation topology: evidence for structural reorganization.
- Improved response to an unseen damage pattern: candidate evidence for generalized adaptation.

This is a research hypothesis, not a claim that the current adapter already demonstrates intelligence or autopoiesis.
