## 2026-09-12 — Core reconciliation started

### Code changes

1. `core/engine.py`
   - Added strict validation requiring `type(steps) is int`.
   - `bool` is no longer accepted as a step count.
   - Added execution support for the canonical `PsiTransition` boundary.

2. `core/evolution.py`
   - Added strict enforcement of `Test(candidate) -> bool`.
   - Truthy non-bool return values now fail with `TypeError`.
   - Added `evolutionary_psi_transition()`, making the fundamental evolution operator explicitly `Psi -> Psi` while retaining State as an implementation adapter for Generate/Test.

3. `core/uroboros.py`
   - Removed silent identity evolution from the default configuration.
   - An unconfigured `Uroboros` now fails closed with `RuntimeError` when stepped.
   - `Uroboros.evolutionary()` now routes through `PsiTransition` rather than the legacy State-only transition.
   - Existing relation replacement path remains explicitly state-backed.

4. `core/psi_transition.py`
   - Corrected the State adapter to use the actual canonical `State.to_psi()` / `State.from_psi()` API.
   - This removes the stale `Psi.from_state(...)` call and makes the boundary executable against the current State implementation.

5. `tests/test_core_contract_repairs.py`
   - Existing regression coverage retained for repaired contracts and relation persistence.

6. `tests/test_psi_core_integration.py`
   - Executable evidence covers evolutionary `Uroboros` using the canonical `PsiTransition`.
   - Direct Engine coverage verifies a `PsiTransition` can cross the State boundary.

### Documentation

- `docs/CORE_CONFORMANCE_MATRIX.md` remains the canonical contract/status matrix.
- `docs/OPEN_DEFECTS.md` remains the active engineering defect ledger.

## Reconciliation result
