# Unseen-damage generalization experiment

This experiment is the next gate after repeated damage.

Protocol:

1. Establish an initial Ψ=(X,R).
2. Apply repeated damage to one relation and retain only the resulting structural state.
3. Apply a different, previously unseen relation damage.
4. Run the same local endogenous dynamics.
5. Compare the response with an unexposed baseline.

The experiment is intentionally weak: it does not yet claim generalized intelligence. The current adapter has no mechanism for creating a missing relation, so a negative result is expected and informative.

A positive result would require a measurable improvement caused by prior structural changes, without a hidden history variable or external selector. That would motivate a next experiment on genuine novel topology generation.
