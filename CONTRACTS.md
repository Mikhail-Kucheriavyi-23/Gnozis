# Gnozis Contract Model

Gnozis uses explicit contracts to connect people and organizations to bounded outcomes.

## Contract lifecycle

```
DISCOVER
  -> PROPOSE
  -> NEGOTIATE
  -> ACCEPT
  -> EXECUTE
  -> VERIFY
  -> COMPLETED / DISPUTED / TERMINATED
```

## Contract fields

A contract may define:

- parties and roles;
- scope;
- deliverables;
- acceptance criteria;
- timeline;
- compensation;
- IP ownership;
- licensing;
- confidentiality;
- security;
- termination;
- referenced repositories and artifacts;
- provenance.

## Important distinction

A GitHub repository, issue, pull request or commit can be a referenced artifact. It is not automatically a legal or commercial contract.

## Capability boundary

A contract grants only the permissions necessary for its defined scope. It does not expose proprietary Kernel internals by default.
