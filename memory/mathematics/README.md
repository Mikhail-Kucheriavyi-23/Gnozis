# Gnozis Mathematics Memory

This directory is the reference implementation of a domain Memory Source.

It demonstrates the common structure for a Gnozis knowledge repository. A future dedicated repository may be split from this reference without changing the protocol.

## Scope

Mathematical knowledge, research records, models, proofs, counterexamples, conjectures, relationships and open problems.

## Trust

This material is a Memory Source. Storage in Git does not make a claim trusted by the Kernel.

Every revision intended for Kernel consumption is identified by its source revision, content digest, schema version and provenance.

## Structure

- definitions/
- models/
- proofs/
- counterexamples/
- conjectures/
- relationships/
- open-problems/
- provenance/
- manifests/
- schema/
