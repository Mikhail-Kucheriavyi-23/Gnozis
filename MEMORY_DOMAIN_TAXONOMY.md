# Gnozis Memory Network — Human Knowledge Map

Gnozis is intended to grow across human knowledge rather than around a fixed list of sciences.

The initial map includes mathematics, physics, chemistry, biology and life sciences, medicine, neuroscience, computer science, AI, engineering, materials science, earth and environmental sciences, astronomy and space, climate and energy, psychology, cognitive science, economics, sociology, anthropology, linguistics, history, philosophy, law and political studies, education, architecture and design, arts and culture, agriculture and food, robotics, systems science, cross-domain research, and open problems.

This is a discovery taxonomy, not a promise that every category immediately receives a separate repository.

## Reusable structure

Domain memory should be machine-readable and versioned. Depending on the field, repositories can contain definitions, models, evidence, observations, proofs, experiments, datasets, methods, counterexamples, hypotheses, relationships, open problems and provenance.

## Cross-domain knowledge

Connections between domains are first-class resources. Gnozis can maintain cross-domain records while preserving provenance to the source domains.

## Community model

Researchers and developers can clone, fork, extend and contribute domain resources using standard GitHub workflows.

The private Kernel can periodically evaluate revisions through an explicit Memory Source Contract. Public repository membership alone does not grant trust or authority.

## Growth rule

Create a new repository when a domain or research community develops a meaningful independent lifecycle, ownership, provenance, access, licensing or collaboration boundary.

This keeps the ecosystem open-ended without forcing a large number of empty repositories at launch.
