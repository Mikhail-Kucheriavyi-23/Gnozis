# Gnozis Ecosystem

Gnozis connects open knowledge, research, capabilities and real-world opportunities around a protected proprietary Kernel.

## People and organizations

The ecosystem supports:

- Researchers — investigate questions and contribute evidence.
- Contractors — execute bounded technical capabilities.
- Partners — collaborate on research, integration or commercial activities.
- Investors — evaluate documented opportunities and resource requirements.
- Maintainers — steward open knowledge and developer resources.
- Users — consume capabilities and results.

## Opportunity flow

```
Question / Problem
  -> Opportunity
  -> Research or Capability
  -> Proposal
  -> Contract
  -> Execution
  -> Verification
  -> Result
```

## Contract principle

A contract defines a bounded scope, deliverables and acceptance criteria. Repository access or GitHub contribution does not itself constitute a contract.

## Trust boundary

People and organizations interact with Gnozis through scoped capabilities. Contracts do not provide general access to the private Kernel.

## Traceability

Where appropriate:

```
Person / Organization
 -> Role
 -> Opportunity
 -> Contract
 -> Artifact
 -> Evidence
 -> Acceptance
 -> Result
```

Public records should expose useful opportunity and research information while keeping confidential commercial terms and proprietary Kernel internals in controlled systems.
